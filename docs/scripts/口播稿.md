## 纯文本（复制用）

我们软件用了经典的三段式状态机控制，用 Efinity 生成了 RISC-V 软核，负责数字信号处理部分。软核调用 DSP 做互相关。模拟部分由易灵思 T20 用 Verilog 编写。

利用 FPGA 并行流水线做互相关，提升了实时处理能力。

利用 SMAC4 自定义指令，互相关使用了全部 DSP。

利用串口屏做显示，节省了资源，方便投入实际应用。

利用双帧 FIFO 和点缓冲，提升了数据搬运效率。

时序收敛验证通过。

## 念的时候

1. **前四句交代技术栈，一口气说完**
2. **五句「利用……提升了……」保持同样节奏**，不要忽快忽慢
3. **「全部 DSP」加重**
4. **「方便投入实际应用」不要吞成「方便应用」**
5. **最后一句「时序收敛验证通过」念完停一秒再停录**
